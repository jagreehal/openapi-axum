---
title: Agent skill
description: "Teach your coding assistant the openapi-axum API."
---

The repository ships an [agent skill](https://github.com/jagreehal/openapi-axum/blob/main/skills/openapi-axum/SKILL.md). Install it so your coding assistant writes routes, responses, extractors and conformance tests with the crate's API:

```bash
npx skills add jagreehal/openapi-axum --skill openapi-axum
```
