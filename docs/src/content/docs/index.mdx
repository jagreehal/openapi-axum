<CardGrid>
  <Card title="One signature" icon="document">
    Path, query, body, responses and doc comments become the OpenAPI operation. You write each endpoint once.
  </Card>
  <Card title="Checked at compile time" icon="approve-check">
    A handler can only return the statuses and bodies its type allows, so the docs list every response it sends.
  </Card>
  <Card title="Validated at runtime" icon="seti:json">
    Bodies, query and path values get checked against the published schemas before your handler runs.
  </Card>
  <Card title="Tested from the docs" icon="rocket">
    `assert_conforms` generates valid and invalid requests from the document and checks every response.
  </Card>
</CardGrid>
